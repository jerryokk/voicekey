## 修复：双击 target/debug/voicekey.exe 报「localhost 拒绝连接」

- 原因：`custom-protocol` feature 没开，Tauri 认为是开发版，启动时去连 devUrl(localhost:1420)，
  而那个 vite 服务器只有 `tauri dev` 才会起。
- 修复：`app/src-tauri/Cargo.toml` 加 `[features] default = ["custom-protocol"]`，
  前端产物（app/dist）在编译期嵌进 exe。改前端后需 `npm run build` + 重新编译；
  热更新开发循环用 `npx tauri dev --no-default-features`（run.cmd 已改）。
- 验证：二进制里找到嵌入的资源路径 `index-BrCBe79f.js`；直接启动 exe，
  无任何到 1420 的连接，隧道就绪（`手机接入已就绪：https://….trycloudflare.com`）。
- 坑：重新编译时若旧 voicekey.exe/cloudflared 还在运行，链接报 os error 32，先杀进程。

## 手机页新增退格键

- 链路：页面 `{op:"backspace", n}` → `Event::Erase(n)`（n 缺省 1、clamp 1..=50）→
  `pf::backspace(n)`（win.rs 原有的 SendInput VK_BACK，改为 pub 并从 platform 导出）。
- controller 在 `self.recording` 时忽略 Erase：流式 Typer 记着已打字数，外部退格会让它失准。
- 页面布局改为 `#ctl` 行：退格（96px 白底描边卡片，⌫ 图标，与 #text 卡片同风格）+ 说话键（flex:1）。
  单击删 1 字，按住 0.42s 后每 80ms 连删；说话期间加 `.off`（opacity .35 + pointer-events none）。
- probe 支持 `--backspace-test`；`backspace-test.mjs` 验证协议（×3 / 缺省×1 / 999→50 全部符合）。
- 踩坑：tauri-codegen 读 codegen-assets 偶报 os error 5（杀软瞬时锁），clean 或重试即过；
  build script 报 os error 32 是旧的 voicekey/cloudflared 还在运行占着 target 下的文件，先杀进程。
